자주 묻는 질문이에요. 앱에서는 설정 → 도움말 → 자주 묻는 질문에서도 볼 수 있어요.

다른 캘린더 노션·슬랙 약속·공유 알림 일정 넣기 Pro·결제 데이터·계정

다른 캘린더

구글 캘린더 두 개(계정 두 개)도 되나요?

네. 휴대폰 캘린더에 구글 계정을 둘 다 추가하면 돼요.

아이폰은 설정 → 앱 → 캘린더 → 캘린더 계정에서 추가하고, 안드로이드는 휴대폰에 로그인한 구글 계정이 바로 보여요.

그다음 1440 설정의 ‘다른 캘린더’에서 보고 싶은 캘린더를 체크해요.

회사(아웃룩) 캘린더는요?

휴대폰 캘린더에 아웃룩 계정을 추가하면 같이 보여요.

아이폰은 캘린더 계정에서 Outlook으로 로그인하고, 안드로이드는 Outlook 앱에서 캘린더 동기화를 켜요.

회사 보안 설정으로 휴대폰 캘린더에 안 들어오면 1440에도 보이지 않아요.

네이버 캘린더는요?

네이버는 CalDAV로 휴대폰 캘린더에 추가하면 같이 보여요.

서버는 caldav.calendar.naver.com, 아이디와 비밀번호는 네이버 것을 넣어요. 2단계 인증을 쓰면 애플리케이션 비밀번호를 넣어요.

자세한 순서는 설정 → 다른 캘린더 → ‘네이버·아웃룩 캘린더가 안 보이면’에 있어요.

구글에서 바꾸면 바로 반영되나요?

같이 보기라면 네. 1440은 휴대폰 캘린더를 그대로 읽어서, 휴대폰에 들어온 변경은 1440을 열 때 바로 보여요.

구글에서 휴대폰까지 오는 데는 휴대폰에 따라 몇 분 걸릴 수 있어요.

1440으로 가져온 일정은 복사본이라 따라 바뀌지 않아요.

가져오기와 같이 보기는 뭐가 달라요?

같이 보기는 원래 캘린더의 일정을 1440에 보여 주기만 해요. 고치는 건 원래 캘린더 앱에서 해요.

가져오기는 1440에 복사해요. 완료 체크, 알림, 옮기기를 할 수 있고, 원래 일정이 바뀌어도 따라 바뀌지 않아요. 같은 일정은 두 번 가져오지 않아요.

캘린더 주소로 추가는 뭐예요?

공휴일, 학사 일정, 구글 캘린더의 공개 주소(iCal)처럼 링크로 된 캘린더를 구독해요. 1440에서는 볼 수만 있어요.

앱을 열 때 12시간이 지났으면 새로 읽어요. 바로 읽으려면 설정에서 그 캘린더를 눌러 ‘새로고침’을 눌러요.

무료로 1개, Pro는 여러 개 추가할 수 있어요.

노션·슬랙

노션에서 원하는 데이터베이스만 연결되나요?

네. 노션 연결 화면에서 1440에 보여 줄 데이터베이스만 골라요. 고른 데이터베이스는 각각 같은 이름의 캘린더로 들어와요.

나중에 바꾸려면 설정 → 노션 연동 → ‘데이터베이스 다시 고르기’를 눌러요.

노션 일반 페이지도 되나요?

아니요. 데이터베이스만 돼요. 제목과 날짜 속성이 있는 항목만 일정으로 가져와요. 날짜가 비어 있는 항목은 건너뛰어요.

노션에서 지우면 1440에서도 빠지나요?

네. 다음에 가져올 때 1440에서도 빠져요. 날짜를 지워도 마찬가지예요.

1440에서 사진이나 기록을 넣은 일정은 지우지 않고 내 일정으로 남겨요.

노션·슬랙을 잠깐 끌 수 있나요?

네. 설정 → 노션 연동에서 ‘노션 일정 가져오기’를 끄면 연결은 두고 가져오기만 멈춰요. 다시 켜면 그동안 바뀐 걸 한 번에 가져와요.

슬랙도 ‘슬랙 메시지를 일정으로 받기’를 껐다 켤 수 있어요. 다시 연결할 필요 없어요.

노션은 실시간으로 바뀌나요?

아니요. 앱을 열 때 마지막으로 가져온 지 3시간이 지났으면 알아서 가져와요. 바로 가져오려면 설정 → 노션 연동 → ‘지금 가져오기’를 눌러요.

1440은 노션을 읽기만 하고, 노션 쪽은 바꾸지 않아요.

노션 데이터베이스를 빼면 가져온 일정은요?

데이터베이스를 다시 고를 때 빠진 게 있거나 연결을 끊으면, 가져온 일정을 어떻게 할지 물어봐요.

‘1440에 남기기’는 노션과 연결 없이 내 일정으로 남겨요. ‘지우기’는 지워요. 사진이나 기록을 넣은 일정은 지워도 남아요.

슬랙 메시지는 어떻게 보내요?

슬랙에서 메시지의 ⋯ → ‘1440 일정으로 추가’를 누르면 돼요. 1440을 열면 메시지에서 일정을 읽어 확인 화면을 보여 줘요.

로그인하고 설정 → 슬랙 연동에서 연결하면 쓸 수 있어요. 오늘 일정 요약을 채널로 보내는 것도 거기서 해요.

노션·슬랙은 무료인가요?

노션·슬랙 연동은 Pro 기능이에요. Pro가 끝나도 이미 가져온 일정은 그대로 있고, 새로 가져오기만 멈춰요. 연결 끊기는 언제든 할 수 있어요.

약속·공유

앱이 없는 친구에게도 보낼 수 있나요?

네. 일정을 열고 ‘약속 보내기’를 누르면 카톡·문자로 보낼 수 있어요. 받은 사람은 같이 간 링크로 구글 캘린더에 바로 넣을 수 있고, 아이폰에서 보내면 캘린더 파일도 붙어요.

로그인해서 보내면 ‘1440에서 답하기’ 링크도 같이 가요.

약속을 바꾸면 상대에게도 바뀌나요?

1440으로 받은 사람은 네. 내가 바꾸면 그 사람 캘린더에서도 같이 바뀌고, 날짜나 시간이 바뀌면 참석할지 다시 물어요.

메시지로만 받은 사람에게는 따라가지 않아요. 바꾼 뒤 나오는 ‘다시 보내기’로 다시 보내 주세요.

받은 약속 시간을 바꾸고 싶어요

받은 약속은 보낸 사람이 바꿔요. 약속을 열고 ‘다른 시간 제안하기’로 날짜와 시간을 골라 보내면, 보낸 사람이 바꿀지 그대로 둘지 골라요.

공유 캘린더와 약속 보내기는 뭐가 달라요?

공유 캘린더는 가족·팀처럼 계속 같이 쓰는 캘린더예요. 멤버 모두 일정을 보고, ‘함께 편집’ 멤버는 누구나 고칠 수 있어요. 투표와 정산도 있어요.

약속 보내기는 일정 하나만 보내요. 내가 만든 약속은 나만 바꾸고, 받은 사람은 참석·불참으로 답해요.

공유 캘린더는 로그인해야 쓸 수 있어요.

투표는 어떻게 해요?

더 보기 → 약속 잡기에서 시간을 여러 개 고르면 돼요. 후보는 10개까지예요.

공유 캘린더 멤버와 정할 땐 투표가 만들어지고, 다른 사람에게는 후보로 보내져요. 받은 사람은 번호로 답하거나 1440에서 골라요.

공유 캘린더의 ‘투표’ 탭에서 직접 만들 수도 있어요.

알림

알림이 안 와요

이렇게 확인해 주세요.

  1. 설정 → 알림에서 ‘알림 받기’가 켜져 있는지
  2. 휴대폰 설정에서 1440 알림이 허용돼 있는지
  3. 집중 모드나 방해 금지가 켜져 있지 않은지
  4. 그 일정에 알림이 있는지(기본은 30분 전)

알림은 앱을 열 때마다 앞으로 한 달 치를 미리 맞춰 둬요. 오래 열지 않았다면 한 번 열어 주세요.

출발 알림은 어떻게 계산하나요?

장소가 있는 일정이면 어디서 출발할지 정해서 걸리는 시간을 어림해요.

앞 일정에 장소가 있으면 거기서, 없으면 평일 근무 시간엔 회사에서, 그 밖엔 집에서 출발한다고 봐요. 그날 첫 일정은 집에서예요.

거리로 대중교통 시간을 어림하고 5분 여유를 더해 알려 줘요. 정확한 길은 알림의 ‘길찾기’로 카카오맵에서 봐요.

집·회사 위치를 설정에서 정해야 하고, Pro 기능이에요.

전날 밤 브리핑은 뭐예요?

내일 일정이 있으면 전날 밤 9시에 ‘내일 일정 3개 · 첫 일정 오전 9:00 팀 회의’처럼 알려 줘요. 남은 준비물이 있으면 그 개수도요.

시간은 설정 → 알림에서 바꿀 수 있어요. Pro 기능이에요.

일정 넣기

카톡으로 받은 약속은 어떻게 넣나요?

카톡 메시지를 복사해서 + 를 누르고 붙여 넣으면 날짜·시간·장소를 알아서 읽어요.

카톡에서 메시지를 길게 눌러 공유 → 1440으로 보내도 돼요.

대화 캡처 사진에서 읽는 건 Pro 기능이에요.

여러 개 한 번에 넣을 수 있나요?

네. + 에서 한 줄에 하나씩, 또는 쉼표로 나눠 적으면 한 번에 들어가요. ‘한 줄씩 확인하고 넣기’로 하나씩 고쳐서 넣을 수도 있어요.

붙여 넣은 메시지에서 한 번에 가져오는 건 무료 5개, Pro 30개까지예요.

루틴과 반복 일정은 뭐가 달라요?

루틴은 시간 없이 매일(또는 매주) 체크하는 습관이에요. 오늘 화면에 칩으로 보여요.

반복 일정은 ‘매주 월 10시 회의’처럼 시간이 있는 일정이 되풀이되는 거예요.

둘 다 더 보기 → 루틴과 반복 일정에서 모아 봐요. 루틴은 무료로 3개까지 켤 수 있어요.

언젠가 할 일은 뭐예요?

날짜를 아직 안 정한 할 일이에요. 더 보기 → 언젠가 할 일에 모아 두고, 날짜가 정해지면 골라서 그날로 옮겨요.

여러 날 일정(여행)은요?

일정에서 ‘종료일’을 정하거나, 월 보기에서 날짜를 길게 누른 채 여러 날을 끌면 돼요. 59일까지 만들 수 있어요.

날마다 일정을 따로 넣을 수 있고, 지난 여러 날 일정은 기록으로 모아 볼 수 있어요.

Pro·결제

무료 체험이 끝나면 자동 결제되나요?

아니요. 처음 쓰기 시작한 날부터 14일 동안 Pro를 써 볼 수 있어요. 결제 정보를 받지 않아서 끝나도 결제되지 않아요.

끝나면 Pro 기능만 잠기고, 일정과 설정은 그대로예요.

무료로 쓸 수 있는 건 어디까지예요?

일정·할 일·알림·캘린더·공유 캘린더·약속 보내기 같은 기본 기능은 모두 무료예요.

Pro에서 열리는 건 이거예요.

  • 출발 알림, 회사 위치
  • 사진·캡처, 음성으로 일정 가져오기
  • 붙여넣기 한 번에 30개(무료 5개)
  • 노션·슬랙 연동
  • D-day·루틴 제한 없이(무료 각 3개)
  • 캘린더 주소 여러 개(무료 1개)
  • 전날 밤 브리핑
해지는 어디서 하나요?

아이폰은 설정 → 내 이름 → 구독, 안드로이드는 Play 스토어 → 결제 및 구독에서 해요. 1440 Pro 화면 아래 ‘구독 관리’를 눌러도 돼요.

기간이 끝나기 24시간 전까지 해지하면 다음 결제가 되지 않아요. 계정을 지워도 구독은 따로 해지해야 해요.

Pro가 끝나면 일정은요?

그대로예요. 만든 일정과 설정은 모두 남고, Pro 기능만 잠겨요.

켜 둔 D-day·루틴도 그대로 두고, 새로 켤 때만 개수를 세요. 출발 알림, 전날 밤 브리핑, 노션 가져오기는 멈춰요.

휴대폰을 바꾸면 구매가 이어지나요?

네. 새 휴대폰에서 같은 Apple ID나 구글 계정으로 1440 Pro 화면의 ‘구매 복원’을 누르면 돼요.

1440에 로그인해서 쓰고 있다면 같은 계정으로 로그인해도 이어져요.

데이터·계정

로그인 없이 써도 되나요?

네. 처음 화면에서 ‘로그인 없이 시작하기’를 누르면 돼요. 일정은 이 휴대폰에만 저장돼요.

공유 캘린더, 약속 링크로 답 받기, 슬랙 메시지 받기는 로그인해야 쓸 수 있어요.

나중에 로그인하면 일정이 합쳐지나요?

네. 이 휴대폰의 일정을 계정으로 옮겨요. 계정에 이미 일정이 있으면 둘 다 남기고, 같은 일정은 두 번 넣지 않아요.

계정에 일정이 있으면 예시 일정은 옮기지 않아요.

휴대폰을 바꾸면 일정은요?

로그인해서 썼다면 새 휴대폰에서 같은 방법으로 로그인하면 그대로 이어져요.

로그인 없이 썼다면 일정이 그 휴대폰에만 있어요. 바꾸기 전에 설정 → 계정 → ‘로그인하고 백업하기’를 해 두세요.

노션·슬랙 연결은 휴대폰에 저장돼서 새 휴대폰에서 다시 연결해요.

내 일정을 파일로 받을 수 있나요?

네. 설정의 ‘내 일정 파일로 내보내기’를 누르면 모든 일정과 메모를 파일 하나로 받아요.

보관용이라 1440으로 다시 불러올 수는 없어요.

계정을 지우면요?

설정 맨 아래 ‘계정 삭제’를 누르면 바로 지워지고 되돌릴 수 없어요. 내 일정, 메모, 사진, 노션·슬랙 연결이 모두 지워져요.

공유 캘린더에 같이 쓰던 일정은 다른 멤버를 위해 남아요. Pro 구독은 스토어에서 따로 해지해 주세요.
